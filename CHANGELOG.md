# Changelog

## 0.1.0

- Introduced the Hiyo engineering product model, combining the supplied Grofloo and Blue Camel concepts.
- Added persistent queue, dependency scheduling, bounded Codex roles, verified Git checkpoints and delivery artifacts.
- Added private React/FastAPI dashboard with real status and local authentication.
- Added Windows setup, startup and Task Scheduler registration scripts.
- Added automated scheduler, controller, security/API and dashboard model tests.

- Standardized the product name as Hiyo across dashboard branding, CLI/package names, Windows scripts, and documentation.

## 0.2.0 product expansion

- Expanded Hiyo into a cross-industry departmental intelligence and workflow platform.
- Added universal REST/GraphQL/SOAP/webhook adapters, explicit approvals and local-first AI.
- Added Firebase-authenticated cloud coordination, PostgreSQL metadata, signed daily device sync and account quotas.
- Added deferred GCP infrastructure and explicit production/cost validation gates.
